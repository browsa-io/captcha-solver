# Security

Report security issues privately to **support@browsa.io**, not in a public issue.

Include what you found, how to reproduce it, and the extension version (shown in `chrome://extensions` or
`about:addons`). We confirm that we received the report and keep you updated until it is fixed.

In scope: the code in this repository and the packages built from it (the Chrome Web Store item and the Firefox
add-on). Issues with Browsa's API or website can go to the same address.
